# Aprender Python

Este es tu primer proyecto de programación. La idea es que abras `main.py` en VS Code, leas los comentarios y vayas completando los ejercicios del final.

## Por qué Python

Es uno de los lenguajes más fáciles de leer para empezar, y sirve tanto para páginas web como para automatizar tareas o trabajar con datos — así que no importa hacia dónde quieras ir después, lo que aprendas acá te sirve.

## Cómo abrir este proyecto en VS Code

1. Abrí VS Code.
2. `File > Open Folder` y elegí la carpeta `aprender-python` (dentro de `~/dev`).
3. Hacé clic en `main.py` en el panel de la izquierda para abrirlo.

## Antes de correrlo: instalar Python (si no lo tenés)

Abrí una terminal y probá:

```bash
python3 --version
```

Si te dice que no existe el comando, instalalo con:

```bash
sudo apt update
sudo apt install python3
```

## Extensión de Python en VS Code

VS Code te va a sugerir instalar la extensión oficial "Python" (de Microsoft) apenas abras un archivo `.py` — aceptá esa sugerencia. Si no aparece sola, andá a la pestaña de Extensiones (ícono de cuadraditos a la izquierda, o `Ctrl+Shift+X`), buscá "Python" e instalá la que dice "Microsoft".

## Cómo correr el programa

Con `main.py` abierto, tenés dos opciones:

- Apretar el botón ▶ (Run) que aparece arriba a la derecha del editor.
- O abrir la terminal integrada (`` Ctrl+` ``) y escribir:

```bash
python3 main.py
```

Vas a ver el resultado en la terminal de abajo. El programa te va a pedir que escribas algo en un punto (con `input()`) — escribí una respuesta y apretá Enter.

## Qué hacer después

1. Leé cada línea de `main.py` y los comentarios que la explican.
2. Cambiá valores (tu nombre, tu edad) y volvé a correr el programa para ver qué cambia.
3. Anda a la sección de "EJERCICIOS PARA VOS" al final del archivo, descomentá cada ejercicio (sacale el `#` de adelante) y completalo vos mismo.
4. Cuando termines, contale a Claude cómo te fue y pedile el siguiente paso.
